# Fractum trademark policy

**The code is Apache-2.0. The name is not.** This file holds the trademark and
brand terms that used to sit at the bottom of `LICENSE`.

They were moved out on 2026-08-19 for a practical reason: appending custom terms
to the Apache text makes GitHub, SPDX and every compliance scanner fail to
recognise the project as Apache-2.0, and it makes a reader in a hurry assume a
restrictive in-house licence. Both happened. The README even described the
project as proprietary and non-commercial, which it never was.

Nothing here restricts what you may do with the source code. The Apache-2.0
grant in [`LICENSE`](LICENSE) is unchanged and unconditional. What follows
concerns only the use of the name "Fractum", the logos and the associated marks,
which Apache-2.0 explicitly does not grant (section 6).
